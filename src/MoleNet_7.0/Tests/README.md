This folder contains the test script and libraries used for testing Molenet V7.0 board.

The test script performs the following checks:

  -LEDs
  
  -Reads data from the BME280 sensor and prints the measurements
  
  -Scans for available Wi-Fi networks and prints
  
  -Tests SD card functionality
  
  -Retrieves and prints data from an SDI-12 sensor (address 1)
  
  -Transmits data over LoRa and waits for incoming LoRa messages for 10 seconds, repeated over three iterations
