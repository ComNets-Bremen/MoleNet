Generates the graphs for the voltage drop over time.

Graphs are postprocessed with Pixelmator Pro to include the battery image in the top right corner. 

The python script [auswertenBK.py](auswertenBK.py) and [auswertenCN.py](auswertenCN.py) uses Pandas and Matpltlib, see requirements.txt, to generate the graphs from the datafiles [BKmoleNET-Data - data.csv](BKmoleNET-Data - data.csv) and [CNMoleNET-Data - data.csv](CNMoleNET-Data - data.csv).
