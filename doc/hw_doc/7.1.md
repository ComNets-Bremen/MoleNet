# Components and their Connections: MoleNet 7.1

This table gives an overview of the used components and their connections.
Please also refer to the corresponding schematic:

[MoleNet 7.1 Schematic](../../PCB-Layouts/MoleNet_v7.1/Molenet_V7.1_Schematic.pdf)


| **Part** | **Part Number**      | **Description**                                                  | **Pins**                                                                                                                                                             |
|----------|----------------------|------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SW1      | SKHHARA010           | Reset button (enable) for ESP32                                  | EN                                                                                                                                                                   |
| SW2      | SKHHARA010           | Boot mode button for ESP32                                       | GPIO0                                                                                                                                                                |
| U1       | [ESP32-S3-WROOM-1-N16](https://www.espressif.com/sites/default/files/documentation/esp32-s3-wroom-1_wroom-1u_datasheet_en.pdf) | ESP32-S3                                                         |                                                            |
| U3       | [TLV76133DCYR](https://www.ti.com/product/de-de/TLV761/part-details/TLV76133DCYR)         | Voltage regulator 3V3, 1N5819 between Vin and the regulator (D1)                                           |                                                       |
| U5       | Ra-01SH               | LoRa Module ([SX1262](https://www.semtech.com/products/wireless-rf/lora-connect/sx1262), [RA-01SH](https://docs.ai-thinker.com/en/Ra-01SH/index.html))                                             | RESET=GPIO15, NSS=GPIO48, MOSI=GPIO47, MISO=GPIO21, SCK=GPIO14, DIO1=GPIO46, BUSY/DIO4=GPIO39   |
| U7       | [BME280](https://www.bosch-sensortec.com/products/environmental-sensors/humidity-sensors-bme280/)               | Sensor for humidity, barometric pressure and ambient temperature | I2C, SCL=GPIO8, SDA=GPIO9, address=0x76 (shared with qwiic connector)     |
| D6       | NCD0805R1            | User LED                                                         | GPIO38                                                                                                                                                               |
| D7       | NCD0805R1            | User LED                                                         | GPIO2                                                                                                                                                                |
| D8       | NCD0805R1            | Power LED                                                        | Power                                                                                                                                                                |
| J1       |                      | Enable SD-card via jumpers                                       | Power=GPIO7 (optional), MOSI=GPIO11, MISO=GPIO13, SCK=GPIO12, CS=GPIO10. You can select the power by one jumper: directly powered or via GPIO.                       |
| J2       |                      | Enable BME280 connection via jumpers                             |                                                                                                                                                                      |
| J3       |                      | Power out                                                        | 2xGND, 3V3, Vin                                                                                                                                                      |
| J4       |                      | Enable LEDs via jumpers                                          |                                                                                                                                                                      |
| J5       |                      | Enable LoRa via jumpers                                          |                                                                                                                                                                      |
| J6       |                      | USB connector. Uses the ESP32 internal USB (D+, D-), use USB-CDC on boot / USB-OTG with TinyUSB (depending on your needs / system)|                                                                                                     |
| J7       |                      | Power in, 5-7V                                                   |                                                                                                                                                                      |
| J8       |                      | Misc. pins (ADC etc.)                                            |                                                                                                                                                                      |
| J9       |                      | Unused GPIOs                                                     |                                                                                                                                                                      |
| J10      |                      | SDI-12 connector                                                 | Uses the following GPIOs: Power=GPIO1, SDI_RX_ENABLE=GPIO36, SDI_RX=GPIO18, SDI_TX_ENABLE=GPIO35, SDI_TX=GPIO17, SDI_MARKING=GPIO37                                  |
| J11      |                      | Remaining DIOs from LoRa transceiver                             |                                                                                                                                                                      |
| J12      |                      | Power connector for energy measurements of the entire board. Connect via jumper                     |                                                                                                                                   |
| J13      |                      | Micro SD card holder                                             |                                                                                                                                                                      |
| J14      | SMA-KWE902           | SMA connector for LoRa                                           |                                                                                                                                                                      |
| J15      |                      | qwiic connector for I2C devices                                  | SCL=GPIO8, SDA=GPIO9 (shared with BME280)                                                                                                                            |
| J16      |                      | Power SDI-12 interface via jumper. Alternative: switch using GPIO1          |                                                                                                                                                           |
| J17      |                      | Jumper for ESP32 power supply. Used to measure only the power consumption of the ESP. Connect via jumper.          |                                                                                                                    |
